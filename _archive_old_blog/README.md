# Old Blog Archive

This directory keeps the pre-2026 blog content after restarting the site.

- `posts/`: archived Hexo/Jekyll migrated posts.
- `assets/`: images and other static files referenced by the archived posts.
- `file/`: archived static files.
- `test.html`: archived legacy test page.

Files in this directory are preserved in the repository but are not part of the Hexo `source/` tree, so they are not generated into the public site.
