# 曲泽慧

硕士阶段主要从事兽医分子病毒学研究，利用病毒反向遗传技术和质谱方法开展 PRRSV 相关工作。博士阶段聚焦兽医微生物与免疫、动物病毒结构生物学和冷冻电镜相关方法，围绕蝙蝠 MHC I 分子的结构生物学与抗原肽递呈机制开展研究，并参与猫杯状病毒等动物病毒的结构解析。

博士后阶段转向神经生物学和神经工程方向，目前主要使用 SEEG 与 MEA 等多通道电生理技术研究癫痫相关网络活动，关注发作间期癫痫样放电（IED）、癫痫灶定位、神经网络传播、微电极阵列记录和多模态数据分析。

## 技能关键词

- SEEG / iEEG：癫痫术前评估数据、IED、SOZ/IZ 相关分析
- MEA：微电极阵列记录、群体放电和网络活动分析
- Signal analysis：多通道电生理信号处理、事件检测、时频分析和可视化
- Python：科研数据处理、自动化脚本、分析流程和结果复核
- Cryo-EM / Crystallography：冷冻电镜与晶体结构解析、结构展示和机制解释
- Immunology / Virology：动物病毒免疫学、病毒结构与宿主互作

## 代表性工作

1. 基于 SEEG/iEEG 数据分析癫痫相关网络活动，关注 IED 形态、空间分布、时间组织和与 SOZ/IZ 的关系。
2. 结合 MEA 记录研究神经元群体放电和网络同步化，为癫痫等神经疾病的机制分析提供电生理证据。
3. 构建可复核的电生理信号分析流程，包括事件检测、时频特征、多通道传播和结果可视化。
4. 解析蝙蝠 MHC class I 分子结构及其 peptidome 特征，研究高亲和力抗原肽结合机制。
5. 参与猫杯状病毒、PRRSV、猫 MHC class I、草鱼 MHC class I 等相关病毒学、免疫学和结构生物学研究。
