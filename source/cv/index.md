# 曲泽慧

在读博士研究生，研究方向为兽医微生物与免疫、动物病毒结构生物学与冷冻电镜相关方法。博士阶段主要围绕蝙蝠 MHC I 分子的结构生物学与抗原肽递呈机制开展研究，同时参与猫杯状病毒等动物病毒的冷冻电镜结构解析工作。

## 代表性工作

1. 解析蝙蝠 MHC class I 分子结构及其 peptidome 特征，研究高亲和力抗原肽结合机制。
2. 参与猫杯状病毒相关冷冻电镜结构研究，结合结构信息理解动物病毒抗原特征。
3. 使用定量蛋白质组学研究高致病性 PRRSV 与其弱毒株感染肺泡巨噬细胞后的膜蛋白差异。
4. 参与 PRRSV、猫 MHC class I、草鱼 MHC class I 等相关病毒学与免疫学研究。
